## 1 不再重新讨论的结论

- 地图不是另一套剧情，地图只是编年步骤的空间投影
- 三维不是随机散点，X/Y 沿用二维方位，Z 只表示原文明示的包含层级
- 地点未知时人物标记隐藏，但该编年步骤仍然存在
- 用户快速点下一步时，人物从屏幕上的当前动画帧继续移动
- 公开部署不能复制本机正式数据库，也不能内置模型密钥
