## 1 本轮实现

- 所有阅读相关派生接口统一使用起始片段、结束片段和防剧透上限；起点之前的上下文带有 `context_only` 标记；终点之后不返回
- 普通章节只作为阅读进度边界；剧情范围选择器只显示有独立证据的故事世界或剧情单元
- 未闭合线索按可执行性区分；阅读页只展示带证据和处理入口的事项；被动记录保留在内部数据
- DeepSeek、Moonshot 和 Codex Luna 都提供配置、连通性、模型可用性和错误状态；探测不发送小说正文，也不改变自动路由资格
- 首次加载、切书、切换窗口、搜索、详情、知识和设置请求显示真实阶段百分比；失败时保留旧内容并提供重试
- 书库树按文件夹深度递增缩进；分析设置页面改用“分析设置与记录”命名；阅读规则和外部事实继续保持独立卡片
- 既有地图几何、2D／3D 共用 `StoryMapStep`、区域约束和增量分析合同保持不变；本轮没有修改原文、正式事实或人工编辑
