# 当前交付状态

本文件是后续任务的第一入口。当前发布目标是 2.6.0，工作范围只有以下五项：

1. 编年、二维地图和三维地图共用同一个 `StoryMapStep`。
2. 二维和三维切换不改变当前步骤、播放状态、地点详情和原文入口。
3. 页面使用黑白灰、清晰间距和可见键盘焦点，主要操作不小于 40 像素。
4. 公开仓库不包含数据库、小说、密钥、日志、内部部署资料或真实用户截图。
5. VPS 只运行空库或合成演示数据，并由 ExampleOrg 的 Authentik 统一登录保护。

## 不再重新讨论的结论

- 地图不是另一套剧情。地图只是编年步骤的空间投影。
- 三维不是随机散点。X/Y 沿用二维方位，Z 只表示原文明示的包含层级。
- 地点未知时人物标记隐藏，但该编年步骤仍然存在。
- 用户快速点下一步时，人物从屏幕上的当前动画帧继续移动。
- 公开部署不能复制本机正式数据库，也不能内置模型密钥。
