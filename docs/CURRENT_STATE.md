## 3 质量处理口径

普通用户只需要关心三件事

- 事实能否逐字回到原文
- 当前书籍是否存在会影响阅读的未解决冲突
- 系统建议的操作会修改哪些关系、编年、地图或知识条目

内部回归样本只用于比较模型、发现退化和保护已修复问题；系统自己维护这套机制，不再向读者展示数量、比例、密封状态或完成任务

项目不会把页面能打开、模型自评或少量固定样本包装成通用准确率；对外质量说明必须写清样本范围和证据边界
