# 当前交付状态

当前发布目标是 `2.9.2-rc.1` 候选版，正式质量门仍由 300 条人工金标准和 60 条有效密封保留案例阻断

## 1 本轮实现

- 地图区域随 `StoryMapStep` 自动联动，当前区域高对比显示，上级区域中等显示，其他区域保留淡化轮廓
- 地点未知时不猜测新区域，只把上一次确认区域标成上次确认
- 区域主名称来自真实地点或原文容器，不再出现编号式故事拓扑片区
- 区域标签移到边界外侧，使用短连接线指回区域，并纳入全图边界计算
- 2D 与 3D 使用相同区域名称、成员、状态和步骤，3D 当前板块提高透明度差异
- 播放支持 `0.5×`、`1×`、`1.5×`、`2×`，速度变化不重置步骤并保存到本机浏览器
- 防剧透进度删除可见编辑按钮，保留双击、Enter、空格、Escape 和失焦保存
- 书库增加来源、语言、许可、真实或虚构标记、导入时间与实际分析范围
- 私有真实语料扩展为 12 部开放作品，合成内容进入功能演示目录

## 2 当前验证证据

- 十二部全文已通过真实下载、格式检查、分章、正文哈希和唯一原文锚点检查
- 文本格式覆盖 TXT、HTML 和 EPUB，语言覆盖中文、英文和日文
- 全部作品共 1,868 个原文片段，正文规模超过 619 万字符
- 十二部作品已逐本通过三栏书库搜索、打开、来源和分析范围浏览器验收
- 120 章压力演示的四个区域均使用真实地点组合命名，步骤切换后当前区域同步变化
- 自动测试和完整浏览器矩阵正在执行，最终数字会在发布提交前回填

## 3 真实质量口径

金标准是人工看过原文后确认的测试答案，机器生成和自动通过都不能代替人工确认

正式质量集为 12 部作品，每部 25 条，其中 20 条开发案例和 5 条密封保留案例，总计 300 条金标准与 60 条密封案例

- 直接覆盖作品为《西游记》《红楼梦》《水浒传》《三国演义》《聊斋志异》
- 开放代理样本为《镜花缘》《海上花列传》、`Pride and Prejudice`、`The Adventures of Sherlock Holmes`、`A Princess of Mars`、`銀河鉄道の夜`、`The Spiraling Web`
- 开放代理样本不能冒充现代商业网文、商业轻小说、现代女频或现代都市小说的直接验证
- 当前机器候选 28 条，可证明的人工确认 0 条，有效密封保留案例 0 条

因此候选版可以报告跨语言、跨文体导入与交互覆盖，不能显示达到 95% 通用小说准确率
