小说证据图谱 2.2.0 已完成 Windows 成品构建和端到端验收

应用当前运行在 `http://127.0.0.1:8765/`，验收数据来自 2026-08-24 的本机数据库、自动测试、浏览器记录和发布包校验

本机数据库质量页记录显示，《西游记》金标准测试达到 28/28，通过率为 $28 \div 28 \times 100\% = 100\%$，关键主体错误为 0

这个结果超过 95% 的验收阈值，证据范围只覆盖当前 28 个金标准案例

## 3 人物关系网

二维关系图使用 fCoSE 力导向与约束布局

fCoSE 是 Cytoscape.js 的快速复合弹簧嵌入布局，适合在关系密集时减少节点和连线碰撞 [4], [5]

正式图只接收已有证据关系的节点

最终浏览器记录显示，默认核心视图包含 32/288 个节点和 76/636 条关系，用户仍可切换查看全部关系

节点支持拖动固定、空白处平移、滚轮缩放、重新布局和视窗适配

鼠标悬停节点时只突出邻居

鼠标悬停连线时显示关系文字，点击节点或连线可以打开证据

三维模式保留旋转和多角度观察，二维与三维位置分别保存

MiroFish 是一个从种子材料构建图谱、运行模拟并生成报告的开源项目，其公开实现把各阶段分开追踪 [6]

本应用采用分阶段思路，同时要求小说事实逐条绑定原文

模拟推演不进入正式小说事实

关系孤立检查默认假设人物或势力存在可追踪关系

系统扫描全部提及窗口后，才能把实体标记为“确认孤立”

## 4 地图实现联动

长篇地点分布在可拖动的大画布上，节点保持可读间距

视窗跟随人物当前位置，当前附近之外的节点在局部模式中完全隐藏

用户点击“显示完整行程”后可以查看全书总览，再切回局部比例

## 5 知识库支持完整管理

世界信息支持搜索、分类筛选、创建、查看、编辑、陈述句指令二次生成、归档和恢复

系统区分原文事实、全书整理和人工补充

二次生成保留候选版本与证据边界

条目数据库覆盖物品、技能、属性、参数和术语

条目页面支持搜索、分类、人工编辑、候选版本预览与修改历史

正文关键词可以跳到条目说明，条目证据可以回到原章节

书库支持文件夹分类、创建、重命名、移动、删除、搜索、导入、导出、整库备份和单书删除

增量更新先按原文前缀与片段哈希核对旧内容

旧剧情没有变化时只处理新增片段

发生冲突时，系统保留旧结果并列出差异，用户可以自动解决或手动确认

## 6 模型处理受到成本约束

处理链路把原始正文、片段提取、证据校验、跨章记忆、身份聚类、时间约束、地图补全、专项复审和质量门禁分开

每个阶段保存输入、输出、提示版本和证据，失败批次可以从本地缓存继续

MiroFish 的阶段化图谱流程为架构对照

小说领域增加了逐字证据、可撤销身份决策和防剧透边界 [6]

DeepSeek V4 是本次使用的模型系列，其思考模式默认开启 [7]

结构化提取请求已明确关闭思考模式，防止思考内容占用输出上限并破坏 JSON 结构

普通提取和初次复审优先使用快速低价模型 `deepseek-v4-flash`

Flash 留下的歧义才升级到高质量模型 `deepseek-v4-pro`

费用按调用时保存的官方价格快照估算 [8]
