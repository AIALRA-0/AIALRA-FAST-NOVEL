## 4 Luna 接入结论

本机 PATH 中的旧 CLI 为 0.128.0，无法读取新版模型目录。应用现在会查找 PATH 和 Codex 桌面应用内置 CLI，并选择基础版本最高的可运行程序

本机旧配置中的 `service_tier = "default"` 已先备份再移除。官方配置说明要求这里使用当前模型支持的层级，`fast` 会映射到请求层的优先处理 [1]

第一次真实请求进一步发现 Codex 严格输出要求每个对象列出全部字段。适配器现在会生成严格结构，并把数据库条目的属性键值对安全还原为内部字典。模型调用成功和正式评估资格也已经分开计算，金标准规模不足不会再被误计为技术故障或触发熔断

真实试跑表明 Luna 能完成小说片段结构抽取，但短片段仍产生了 19,617 个输入标记。正式赛马需要继续比较每个合格事实的调用量、耗时和质量，不能只依据“订阅内可用”判断它比 API 更便宜
