# 小说证据图谱产品合同

## 1 目标

系统把长篇小说整理为可核验的人物关系、故事编年、逻辑地图、世界信息和条目数据库

每条正式结论必须能够回到当前书籍的逐字原文；用户补充的阅读规则可以改变分析方法，外部资料始终单独保存，不能伪装成原文证据

## 2 质量门禁

- 正式证据逐字命中率必须为 100%
- 关键主体误认、未解决关键冲突、时间循环和静默地点猜测必须为 0
- 编年、二维地图、三维地图、播放条和原文跳转必须使用同一份步骤序列
- 内部回归评测由系统和维护流程自动执行；不进入普通界面，也不要求读者建立题库、理解评测术语或完成审核任务
- 任何对外准确率声明必须说明作品、样本、文体和测试日期；没有足够证据时不显示该数字

注：自动测试通过只能证明当前固定样本和软件行为，不代表任意小说天然达到相同结果

开放作品中的相近文体只作为代理样本，现代商业网文、商业轻小说、现代女频和现代都市小说在取得明确授权前不得宣称已经直接验证

## 3 协作规则

- 用户原话、系统理解、验收条件、影响范围、成本变化和验证证据保存在同一协作事项中
- 可逆的小改动自动执行
- 改变产品目标、核心证据规则、成本上限或正式发布时必须由用户确认
- 具体事实纠正自动进入内部回归记录；普通用户只需要修正当前事实，不负责维护测试集
- 连续两轮没有改善目标指标时停止堆叠提示词并重新审计根因

## 4 模型规则

- DeepSeek、Kimi 和 Codex Luna 使用同一原文、提示词、结构检查和内部回归样本赛马
- 关键事实或证据检查存在失败的模型不能进入自动路由
- API 模型展示可复算美元费用
- ChatGPT 登录通道只展示真实调用量、令牌量、耗时和可获得的额度状态
- Codex CLI 只处理用户主动启动的本机任务

## 5 明确排除

- 不用常识或其他版本作品补写小说原文没有说明的事实
- 不把行程先后猜成现实方位
- 不把模型自评当作事实证据或质量结论
- 只自动下载清单中来源、许可和哈希可追溯的公版或开放许可作品
- 开放全文只进入 Authentik 保护的私有书库，公开仓库和未登录接口不保存或返回全文
- 不把密钥、小说全文或登录凭据写入版本记录
