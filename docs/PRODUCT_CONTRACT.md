# 小说证据图谱产品合同

## 1 目标

系统把长篇小说整理为可核验的人物关系、故事编年、逻辑地图、世界信息和条目数据库

每条正式结论必须能够回到当前书籍的逐字原文；用户补充的阅读规则可以改变分析方法，外部资料始终单独保存，不能伪装成原文证据

## 2 质量门禁

- 每本参与发布评估的真实作品至少有 20 条已确认金标准
- 五部真实作品合计至少有 300 条已确认金标准
- 关键主体、身份、核心关系、主线顺序和主要行程案例必须全部通过
- 保留测试加权准确率至少为 95%
- 正式证据逐字命中率必须为 100%
- 关键主体误认和未解决关键冲突必须为 0

注：准确率只代表公开测试集上的实测结果，不代表任意小说天然达到相同数值

## 3 协作规则

- 用户原话、系统理解、验收条件、影响范围、成本变化和验证证据保存在同一协作事项中
- 可逆的小改动自动执行
- 改变产品目标、核心证据规则、成本上限或正式发布时必须由用户确认
- 具体事实纠正直接进入回归候选，确认后成为永久测试
- 连续两轮没有改善目标指标时停止堆叠提示词并重新审计根因

## 4 模型规则

- DeepSeek、Kimi 和 Codex Luna 使用同一原文、提示词和金标准赛马
- 关键案例存在失败的模型不能进入自动路由
- API 模型展示可复算美元费用
- ChatGPT 登录通道只展示真实调用量、令牌量、耗时和可获得的额度状态
- Codex CLI 只处理用户主动启动的本机任务

## 5 明确排除

- 不用常识或其他版本作品补写小说原文没有说明的事实
- 不把行程先后猜成现实方位
- 不把模型自评当作人工金标准
- 不主动下载来源或授权不明确的商业小说
- 不把密钥、小说全文或登录凭据写入版本记录
