# 小说证据图谱 1.2.0 最终验证报告

核验日期：2026-08-24

本报告记录小说证据图谱 1.2.0 的端到端验证结果。全部数量来自自动测试、浏览器实测、本机隔离数据库、DeepSeek 返回的用量字段和 Windows 成品启动记录。

## 1 验证结论

1.2.0 已形成从普通小说导入、长篇分段、模型提取、跨章节复核，到人物关系网、行程地图、编年史、世界信息、数据库、证据核验和费用统计的完整链路。

这次不再使用为了测试而编排好的结构化短文作为主要依据。系统实际读取 Project Gutenberg 公版《西遊記》全文，共处理 203 个正文片段，最终保存 2,980 条有原文依据的结构记录[1]。

界面完成三项关键修正：人物图支持自然拖动、悬停聚焦、二维缩放和三维旋转；地图按照方位、明确地理关系和主角路线布局；详情改为左侧导航、中间主视图、右侧固定证据栏，查看原文时不会再遮住或模糊图表。

所有已保存结构记录都能回到真实章节和逐字原文。证据链完整只能证明“系统能指出依据”，不能单独证明模型的每项语义判断都正确。同名人物、化名、梦境、倒叙和叙述误导仍需要人工复核。

## 4 费用与缓存验证

费用依据每次请求返回的输入令牌、缓存命中输入、缓存未命中输入和输出令牌计算。任务创建时保存价格快照，因此供应商日后调价不会改写历史账单。DeepSeek 当前价格说明见官方文档[2]。

表 3 《西遊記》真实分析费用

| 任务 | 处理内容 | 输入令牌 | 输出令牌 | 缓存命中输入 | 记录费用 |
|---|---|---:|---:|---:|---:|
| 任务 1 | 前 5 个片段 | 46,576 | 19,039 | 23,168 | 0.02888482 美元 |

任务 2 在一个片段持久化失败后发生过内部重试。1.2.0 会把供应商已经返回但随后入库失败的调用也计入费用，防止实际花费被漏记。

## 5 人物关系网验证

默认关系图只显示核心人物和重要关系，用户可切换完整关系网。二维模式适合阅读关系，三维模式适合从多个角度拆开密集连接。两种模式都支持拖动、缩放、悬停和点击证据。

节点开始拖动时，镜头导航会暂时停止，释放节点后立即恢复。这个处理消除了“拖人物时镜头也跟着转”和释放节点后无法继续缩放的问题。

悬停人物时，只强调该人物、相邻角色和直接关系。其余节点与连线降低可见度，关系文字跟随当前焦点显示。箭头缩小到适合细线的尺寸，避免遮住人物名称。

首次出现不再显示“片段 1”一类内部编号。右侧证据栏显示真实章节，例如孙悟空的首次出现为“第一回 靈根育孕源流出 心性修持大道生”。

## 6 行程地图验证

地图只保留主角实际行进路线、当前步骤附近地点和有直接地理联系的地点，不再把所有提到过的地点围成一圈。

地点坐标优先使用文本提取出的东、西、南、北、相邻、包含和路线关系。原文缺少明确方位时，系统按照主角行程生成可读的折线路径，同时运行标签避让，确保地点名称不会被节点或其他文字遮住。

点击“下一步”后，人物标记会从上一个地点移动到下一个地点，当前路线同步高亮，中间区域同时更新事件、故事时间、交通方式、在场人物和原文章节。用户也可以点地图地点查看当地发生过的历史。

## 7 世界信息去重验证

旧版重复的主要原因是每个片段分别提取规则，随后直接把措辞略有差异的卡片全部展示。1.2.0 增加跨章节归并，并把同一主题的原始事实收进综合结论的证据链。

去重同时比较规范标题、关键词组合、文字相似度和证据范围。紧箍约束、天界与人间时间差、狮驼岭三妖和天兵体系等明显重复主题，在界面中都只保留一张综合卡片。原始证据没有删除，用户仍可从综合卡片逐条核验。

## 8 数据正确性修复

全书实跑发现，旧查询把任务队列编号误当成正文片段编号。短篇演示中两者经常相同，因此早期测试没有暴露；连续处理 203 个真实片段时，错误最终触发数据库约束。

1.2.0 已明确使用正文片段编号保存证据，并在启动时检查历史数据库。发现证据指向其他书的片段时，系统会根据任务记录自动修复。修复后的《西遊記》跨书错误证据为 0 条，新增回归测试覆盖了新任务和旧数据修复两条路径。

## 9 描述文字与提示词

提取提示词改为完整规范，明确要求区分原文事实和解释、保留准确引文、识别倒叙与回忆、拆分地理关系和人物行程、避免模板句、跨章节去重，并在信息不足时降低置信度。全书复核使用另一套长提示词，负责别名、冲突、世界规则和时间顺序的综合判断。

最终数据库扫描没有发现旧演示中的机械模板短语。抽样事件包含具体人物、地点、行动和结果，不再用“参与某事并推进主线”替代内容。

## 10 安全与恢复

- 开放平台密钥由 Windows 数据保护接口加密，接口只返回配置状态，不返回明文。
- EPUB 导入会拒绝路径穿越、加密出版物、异常压缩、外部地址和脚本。
- 模型输出只是候选。候选引文必须在当前正文片段中逐字找到，才能写入数据库。
- 每个片段单独提交。应用意外退出后，已完成片段根据正文、供应商、模型和提示版本复用。
- Windows 服务只监听 `127.0.0.1`，同一局域网的其他设备无法直接访问。

## 11 已知边界

- Moonshot 开放平台适配器已经实现。本次提供的 Kimi Code 凭据不是 Moonshot 开放平台密钥，供应商拒绝调用，因此真实长篇验收使用 DeepSeek。
- 扫描版 PDF 如果没有文字层，当前版本不会进行光学字符识别。
- 地图方位只在原文提供方向、相邻或路线证据时代表故事中的地理事实。其余坐标用于保持路线可读，界面会把它视为布局位置。
- 100% 证据覆盖表示每项记录都能回到原文，不表示模型理解的准确率达到 100%。
- 首次分析成本随书长、输出密度、失败重试和供应商价格变化。缓存主要降低重复分析成本。
- 74 组实体合并候选仍需人工判断。这是避免误合并的主动限制。
