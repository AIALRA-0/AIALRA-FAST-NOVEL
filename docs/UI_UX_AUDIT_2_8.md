# 2.8.0 界面问题台账

本台账记录 2.8.0 的界面缺陷、影响、修改和验收证据，真实小说截图只保存在本机忽略目录，不进入公开仓库

## 1 验收范围

- 配置文件设定桌面浏览器视口为 1440×900 与 1366×768
- 配置文件设定窄屏浏览器视口为 720×960
- 鼠标、键盘、拖动、缩放、快速连续点击和二维三维切换
- 合成固定数据与五部真实公版全文

## 3 当前证据边界

- 五部真实全文已经验证导入、切分、书库检索和打开流程
- 本地验收数据库显示，《西游记》已经验证双向关系、157 个地点、45 个可用语义区域、三维区域渐进显示、1,049 个编年步骤与末步结束状态
- 门禁配置设定目标准确率为 95%，其他四部作品尚未完成模型抽取与人工金标准，因此当前证据不支持该结论
- 产品合同设定每部至少 20 条人工确认案例、总计至少 300 条、20% 保留测试和关键案例 100% 通过，正式发布尚未满足这些条件
