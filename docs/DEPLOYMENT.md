# 受保护部署说明

公开实例只用于你本人登录后的远程使用。部署包不携带本机数据库、上传小说或模型密钥。

## 固定边界

- 应用容器只绑定 VPS 的 `127.0.0.1`，公网不能绕过 Nginx 直接访问。
- Nginx 的全部页面和接口都经过 ExampleOrg 统一身份网关；登录由 Authentik 完成。
- 容器使用非 root 用户、只读根文件系统、独立数据卷、无额外 Linux 能力和进程、内存、CPU 上限。
- `/healthz` 与 `/readyz` 只返回版本和健康状态，不返回书库、账户或模型信息。
- 在线实例的登录后私有书库包含 12 部来源与许可可追溯的开放作品，合成演示单独放在功能演示目录
- 公共仓库只保存语料清单、来源、许可证和哈希，不保存十二部作品全文或分析数据库
- 页面必须展示实际分析范围，首批局部分析不能冒充全书完成
- Linux 服务器不会保存网页提交的模型密钥。需要模型调用时，只能由管理员通过服务器密钥管理注入环境变量。

## 可回滚更新

更新前先备份命名数据卷，并保留上一版容器镜像。新镜像通过本机健康检查、Nginx 配置检查和登录跳转检查后再切换。失败时停止新容器、恢复上一镜像和数据卷，不修改 Authentik 主身份数据。
