## 2 冲突处理

统一冲突中心覆盖身份候选、事实矛盾和时间顺序冲突

自动处理只运行本地规则，所以不会产生模型费用

- 证据不足的身份保持分离
- 可能冲突的事实进入隔离区
- 造成时间循环的约束会被舍弃
- 剧情事件和原文证据继续保留

用户可以逐条改判，应用会保存理由、处理者和处理时间

身份支持合并或分离，事实支持不同情境、误报或隔离，时间约束支持反转、舍弃或隔离
