# 真实小说评估集

## 1 数据原则

这里保存评估集定义、用户纠正目录和可公开的预期结果。小说全文继续保存在本地数据库，不进入版本记录

人工金标准必须包含具体书籍、原文章节、预期结论和人工核对说明。模型生成的候选只有经过用户确认后才能计入准确率

## 2 案例状态

- 候选：系统生成并定位原文，尚未经过人工核对，不计入准确率
- 已确认开发案例：人工看过原文并接受或修正，可用于调试
- 密封保留案例：人工确认后隐藏答案，只在正式评测中运行
- 已裁决：关键案例或保留案例完成第二遍复核，分歧已经处理

每次人工确认保存审核人、时间、原文哈希、修改前后答案和复核状态

## 3 正式质量门槛

- 至少5部叙事结构不同的真实作品
- 合计至少 300 条已确认金标准
- 每部60条，其中48条开发案例、12条密封保留案例
- 60条密封保留案例全部完成第二遍复核
- 关键案例覆盖主体、身份、关系、时间、地点和行程

正式语料范围由 `quality_corpus_manifest.json` 定义，包括《西游记》《红楼梦》《三国演义》、1部用户授权的现代玄幻长篇、1部用户授权的现代都市或翻译长篇

## 4 当前状态

应用会从数据库实时计算已确认数量和保留测试比例。数量不足时页面明确显示“尚未校准”，不会把结构完整率冒充内容准确率

当前数据库中的28条程序预置题已经迁移为候选，可证明的人工确认案例为0，有效密封保留案例为0

本机“公版评估语料”文件夹已经准备《西游记》《水浒传》《红楼梦》《三国志演义》和《聊斋志异》5部 Project Gutenberg 公版文本，这5部仍用于导入、书库和古典小说浏览器流程，其中《水浒传》和《聊斋志异》不再占用正式混合五书质量集的现代作品名额

现代作品必须由用户确认本机评测授权，小说全文只保存在本机，不进入版本记录；两部现代作品就位并完成全部人工核对前，项目只能报告古典小说覆盖率，不能宣称通用小说准确率

公网浏览器验收只检查域名、登录、书库、地图、编年和知识库能否正常使用，不计入内容准确率

`regression_catalog.json` 保存历次用户反馈对应的回归类别。它是测试目录，不是小说事实
